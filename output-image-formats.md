# Format Gambar Keluaran

### TIFF (16-bit)

16-bit (nilai piksel digital 0 - 65535) dalam format keluaran TIFF (.tif).

### TIFF (32-bit, Persen %)

32-bit (nilai float piksel 0,0 - 1,0) format keluaran TIFF (.tif). Nilai piksel mewakili persentase reflektansi di mana 0,0 = 0% dan 1,0 = 100%.

### **JPG (8-bit)**

8-bit (angka digital piksel 0 -255) Keluaran dalam format JPG (.jpg).

### **PNG (8-bit)**

Output format PNG (.png) 8-bit (angka digital piksel 0 - 255). Kompresi tanpa kehilangan data yang cocok untuk tampilan web dan visualisasi.
