# Antarmuka Pengguna: Proyek

Chloros memungkinkan Anda membuat proyek yang dapat dibuka kembali di kemudian hari.

## Proyek Baru

<figure><img src=".gitbook/assets/project_new.JPG" alt=""><figcaption></figcaption></figure>Pilih &quot;Proyek Baru&quot; dari menu utama dan masukkan nama unik untuk proyek Anda.

## Buka Proyek

<figure><img src=".gitbook/assets/project_open.JPG" alt=""><figcaption></figcaption></figure>Pilih &quot;Buka Proyek&quot; untuk melihat daftar proyek yang ada di Folder Proyek. Jika tidak ada proyek, menu samping sekunder tidak akan terbuka. Anda dapat melihat beberapa proyek yang dibuat oleh GUI (t1, t2, t3) tercantum pada foto di atas. Proyek-proyek DATE\_TIME dibuat oleh CLI menggunakan skema penamaan proyek default. Mengklik nama proyek mana pun akan membukanya.

Mengklik tombol &quot;Buka Folder Proyek&quot; akan membuka penjelajah file komputer Anda di jalur proyek. Anda dapat menyesuaikan jalur proyek di [Pengaturan Proyek](project-settings/project-settings.md).

## Tambahkan File

Setelah proyek dibuka, pilih &quot;Tambahkan File&quot; dari menu utama untuk menambahkan file gambar individu ke proyek saat ini. Fungsi ini mirip dengan fitur tambah di penjelajah file, tetapi dapat diakses langsung dari menu utama untuk kemudahan.

## Tambahkan Folder

Setelah proyek dibuka, pilih &quot;Tambahkan Folder&quot; dari menu utama untuk menambahkan seluruh folder gambar ke proyek saat ini. File duplikat akan diabaikan.

## Mulai / Hentikan Pemrosesan

Setelah berkas ditambahkan ke proyek, opsi &quot;Mulai Pemrosesan&quot; akan tersedia di menu utama. Ini sama dengan mengklik tombol Putar/Mulai di bilah atas. Selama pemrosesan, opsi menu berubah menjadi &quot;Hentikan Pemrosesan&quot; untuk memungkinkan Anda menghentikan alur kerja.

{% hint style="info" %}
Opsi menu &quot;Tambahkan File&quot;, &quot;Tambahkan Folder&quot;, dan &quot;Mulai/Hentikan Pemrosesan&quot; hanya terlihat atau aktif saat proyek terbuka dan file telah ditambahkan. Opsi-opsi ini menyediakan akses cepat ke tindakan yang juga tersedia melalui bilah samping Penjelajah File dan tombol-tombol di bilah atas.
{% endhint %}
